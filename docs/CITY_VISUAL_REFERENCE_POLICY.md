# City Visual Reference and Asset Provenance

## Requested visual reference

- Reference search: https://community.fandom.com/wiki/Special:Search?scope=cross-wiki&query=Sims+city+biuld+it&ns%5B0%5D=6&filter=imageOnly
- Intended use: visual research for city scale, architectural variety, district identity, public-service buildings, roads, landscaping, and progression presentation.
- The search page is a discovery index, not an asset license.

## Copyright and asset intake

Fandom states that non-text media is not automatically covered by the wiki text license. Each file must be checked on its own description page for its author, source, and license. Screenshots and artwork from SimCity BuildIt must therefore not be copied into this repository or shipped in the game unless the specific rights holder has granted a compatible license or written permission.

Official guidance:
- https://www.fandom.com/licensing
- https://support.fandom.com/hc/en-us/articles/360035075654-I-want-to-reuse-text-or-images-from-a-Fandom-wiki
- https://community.fandom.com/wiki/Copyright

## Implementation rule

- Use the requested search results as visual references only unless a specific image has a verified reuse license.
- Prefer original Mshin illustrations and locally stored GLB/GLTF/SVG assets with source, author, license, and attribution recorded.
- Never hotlink Fandom or game-CDN images at runtime.
- For every approved third-party asset, add a provenance record with the exact file URL, creator/uploader, license, license URL, retrieval date, and any required attribution.
- Do not label an original Mshin illustration as an official SimCity BuildIt asset.

## Current catalog

The assets/city-catalog/ SVGs are original Mshin vector illustrations. They are category previews, not copied SimCity BuildIt screenshots and not yet a complete library of production 3D building models.
