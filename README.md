# Pasoo City BuildIt 🏙️

**نسخه Godot بازی: 1.0.0 — هسته قابل بازی + نسخه مرورگری در حال انتشار**

[![PLAY MSHIN](https://img.shields.io/badge/▶%20PLAY-MSHIN-19b77a?style=for-the-badge)](https://pasoooir.github.io/Mshin/game/latest/)

### اجرای بازی با یک کلیک
روی دکمه **PLAY MSHIN** بالا بزن؛ لینک مستقیماً نسخه مرورگری بازی را اجرا می‌کند و برای اجرای آن نیازی به نصب Godot نیست. بازی در همان لحظه ورود، به‌صورت خودکار درخواست حالت تمام‌صفحه و قفل افقی (Landscape) می‌دهد. این قابلیت به مجوز و پشتیبانی مرورگر وابسته است؛ در مرورگرهایی که آن را مسدود می‌کنند، بازی بدون توقف در حالت قابل‌نمایش اجرا می‌شود و اولین لمس/کلیک داخل بازی نیز دوباره درخواست را امتحان می‌کند.

### اجرای نسخه Godot برای توسعه
1. Godot 4.3 یا جدیدتر (Standard) را نصب کن.
2. پوشه `godot-city-buildit` را از همین Repository با گزینه Import در Godot Project Manager باز کن.
3. فایل `godot-city-buildit/project.godot` نقطه ورود پروژه است؛ برای اجرا F5 را بزن.

GitHub Actions به‌صورت خودکار پروژه را بررسی، برای مرورگر خروجی Web تولید و در GitHub Pages منتشر می‌کند. همچنین می‌توان انتشار را از زبانه Actions با اجرای دستی workflow با نام **Mshin Playable Web** آغاز کرد.

**توجه:** نسخه Godot در پوشه مستقل نگهداری می‌شود. نسخه Web از رندرر GL Compatibility استفاده می‌کند تا با مرورگرهای موبایل سازگار باشد.

### 🟡 توسعه‌های بعدی
هسته اصلی قابل اجراست. زیرمرحله نخست فاز ۰.۱ بهبودهای رویه‌ای محیط و ساختمان را دریافت کرده است؛ مدل‌های معماری GLB باکیفیت، تست عملکرد واقعی روی موبایل و تنظیم نهایی کیفیت بصری هنوز باقی‌اند. حمل‌ونقل، خدمات شهری پیشرفته و اقتصاد گسترده نیز در نقشه راه ادامه دارند.
لیست کامل در بخش «نقشه راه» پایین آمده است.

## فاز ۰ — پایه و حس بازی (اولویت فوری)

### ۰.۱ ظاهر و مدل‌ها
- [~] مدل‌های سه‌بعدی در سطح نهایی و متنوع BuildIt هنوز کامل نیستند؛ چهار مدل GLTF برای ساختمان‌های قابل‌بازی (ویلا، آپارتمان میان‌مرتبه، فروشگاه و کارخانه) وارد شده‌اند؛ مدل برج ۷۴٫۵۷۵ متری نیز به‌عنوان asset محلی آماده است، اما تا زمان پشتیبانی footprint بزرگ به ساختمان ۲×۲ فعلی متصل نشده است و بارگذاری آفلاین آن‌ها آزمون CI دارد. این مدل‌ها هندسه جزئیات‌دار و تکسچرهای PBR رویه‌ایِ تعبیه‌شده (Base Color، Normal و Metallic-Roughness) دارند، اما هنوز تکسچرهای عکاسانه با وضوح بالا و تنوع معماری نهایی ندارند.
- [x] بارگذاری مدل‌های GLB/GLTF از مسیر محلی `assets/models/` با اعتبارسنجی مسیر، مقیاس اختیاری و بازگشت امن به مدل رویه‌ای در صورت نبود/نامعتبر بودن فایل.
- [x] چهار مدل GLTF محلی و آفلاین برای ویلا، آپارتمان میان‌مرتبه، فروشگاه تجاری و کارخانه، به‌علاوه یک مدل برج ۷۴٫۵۷۵ متری که هنوز به ساختمان قابل‌بازی متصل نشده است؛ مدل‌ها دارای تکسچرهای PBR رویه‌ایِ داخلی Base Color، Normal و Metallic-Roughness هستند و تست GameplaySmoke بارگذاری صحنه و وجود MeshInstance3D را برای هر چهار فایل بررسی می‌کند. مدل فروشگاه و کارخانه در این مرحله نمای عمومی دسته هستند، نه مدل اختصاصی هر برند/کاربری؛ ویژوال اختصاصی Building Supplies، Art Supplies و ویلای مرحله اول حفظ شده است.
- [x] اعتبارسنجی CI فقط مسیرهای واقعاً استفاده‌شده در فراخوانی‌های بارگذاری منبع Godot را بررسی می‌کند؛ رشته‌های آزمایشی `res://` به‌اشتباه وابستگی فایل تلقی نمی‌شوند و این رفتار تست رگرسیون دارد.
- [x] جزئیات رویه‌ای ساختمان‌ها: پنجره قاب‌دار، ورودی، سایه‌بان، دودکش، تابلو و جزئیات سقف
- [x] زمین چندطیفی، علف‌های سه‌بعدی MultiMesh، آسفالت procedural، جدول و پیاده‌رو
- [x] آب ساحلی چندرنگ با موج متحرک، ناحیه کم‌عمق فیروزه‌ای و جزئیات ساحل
- [x] نور گرم‌تر، نور محیطی و مه جوی سبک
- [x] افکت ذرات سبک هنگام تکمیل ساخت

## قوانین توسعه (اجباری)

1. **ظاهر و حس** باید نزدیک به SimCity BuildIt باشد (رنگ‌ها، آیکون‌ها، جریان بازی).
2. منوهای اصلی صفحه شهر **فقط با آیکون** کار کنند.
3. کنترل دو انگشتی زوم را خراب نکن.
4. جدول Level Up و راهنمای رسمی EA مرجع اصلی باز شدن امکانات است.
5. کد تمیز، کامنت‌دار و قابل توسعه بنویس.
6. از `Resource` برای تعریف ساختمان‌ها و آیتم‌ها استفاده کن.
7. بعد از هر فاز/مرحله گزارش کوتاه بده و سپس ادامه بده.

→ ساخت فروشگاه تجاری و ساخت آیتم

## نحوه اجرا الان

1. Godot 4.3 یا بالاتر را نصب کن
2. پروژه را Import کن
3. صحنه `scenes/main.tscn` را اجرا کن

**کنترل‌ها**
- یک انگشت / درگ موس → جابه‌جایی نقشه
- دو انگشت / اسکرول → زوم
- ضربه / کلیک → ساخت، جمع‌آوری، یا ارتقای خانه
- دکمه‌های سمت چپ → انتخاب ابزار (فقط آیکون)
