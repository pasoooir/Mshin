# Pasoo City BuildIt 🏙️

**نسخه Godot بازی: 1.0.0 — هسته قابل بازی + نسخه مرورگری در حال انتشار**

[![PLAY MSHIN](https://img.shields.io/badge/▶%20PLAY-MSHIN-19b77a?style=for-the-badge)](https://pasoooir.github.io/Mshin/)

### اجرای بازی با یک کلیک
روی دکمه **PLAY MSHIN** بالا بزن؛ نسخه مرورگری بازی در GitHub Pages اجرا می‌شود و برای اجرای آن نیازی به نصب Godot نیست. بازی در همان لحظه ورود، به‌صورت خودکار درخواست حالت تمام‌صفحه و قفل افقی (Landscape) می‌دهد. این قابلیت به مجوز و پشتیبانی مرورگر وابسته است؛ در مرورگرهایی که آن را مسدود می‌کنند، بازی بدون توقف در حالت قابل‌نمایش اجرا می‌شود و اولین لمس/کلیک داخل بازی نیز دوباره درخواست را امتحان می‌کند.

### اجرای نسخه Godot برای توسعه
1. Godot 4.3 یا جدیدتر (Standard) را نصب کن.
2. پوشه `godot-city-buildit` را از همین Repository با گزینه Import در Godot Project Manager باز کن.
3. فایل `godot-city-buildit/project.godot` نقطه ورود پروژه است؛ برای اجرا F5 را بزن.

GitHub Actions به‌صورت خودکار پروژه را بررسی، برای مرورگر خروجی Web تولید و در GitHub Pages منتشر می‌کند. همچنین می‌توان انتشار را از زبانه Actions با اجرای دستی workflow با نام **Mshin Playable Web** آغاز کرد.

**توجه:** نسخه Godot در پوشه مستقل نگهداری می‌شود. نسخه Web از رندرر GL Compatibility استفاده می‌کند تا با مرورگرهای موبایل سازگار باشد.

## قوانین توسعه (اجباری)

1. **ظاهر و حس** باید نزدیک به SimCity BuildIt باشد (رنگ‌ها، آیکون‌ها، جریان بازی).
2. منوهای اصلی صفحه شهر **فقط با آیکون** کار کنند.
3. کنترل دو انگشتی زوم را خراب نکن.
4. جدول Level Up و راهنمای رسمی EA مرجع اصلی باز شدن امکانات است.
5. کد تمیز، کامنت‌دار و قابل توسعه بنویس.
6. از `Resource` برای تعریف ساختمان‌ها و آیتم‌ها استفاده کن.
7. بعد از هر فاز/مرحله گزارش کوتاه بده و سپس ادامه بده.

## نحوه اجرا الان

1. Godot 4.3 یا بالاتر را نصب کن
2. پروژه را Import کن
3. صحنه `scenes/main.tscn` را اجرا کن

**کنترل‌ها**
- یک انگشت / درگ موس → جابه‌جایی نقشه
- دو انگشت / اسکرول → زوم
- ضربه / کلیک → ساخت، جمع‌آوری، یا ارتقای خانه
- دکمه‌های سمت چپ → انتخاب ابزار (فقط آیکون)
