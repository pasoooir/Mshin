# Mshin — 2D Top-Down Arcade Racing

Mshin is a colorful top-down arcade racing game targeting Cocos Creator 3.8.6 + TypeScript.

## Current implementation

- Cocos runtime components are in assets/scripts/.
- Engine-independent game logic and the deterministic 50-stage catalog are in src/.
- 10 themed worlds and 50 distinct procedural route definitions are generated by src/stage-catalog.ts.
- Offline progress and best times are stored with Cocos sys.localStorage.
- Cloudflare R2 is not used.

## Open in Cocos Creator

1. Install Cocos Creator 3.8.6.
2. Open this repository folder from Cocos Dashboard.
3. Create a 2D scene under assets/scenes/ using the Editor.
4. Add a root node and attach assets/scripts/MshinGame.ts as a component.
5. Save the scene and set it as the startup scene in Build Settings.

Editor gate: the development container does not include Cocos Creator. A verified .scene asset and Editor import/build have therefore not yet been generated. Do not treat Node tests as an Editor build.

## Validate portable game logic

Requires Node.js 20+ and npm. Run npm install, then npm run check.

This compiles and tests engine-independent TypeScript only. Cocos scripts are compiled by the Cocos Editor with its own engine declarations.

## Existing browser prototype

index.html and src/game.js remain as an earlier browser prototype/reference, not the final Cocos deliverable.

## Stage data and artwork

- data/worlds.json and data/stages.json: planning metadata.
- cdn/previews/: 50 SVG concept previews, not final in-game stages.
- src/stage-catalog.ts: runtime stage/world definitions and procedural route generation.
